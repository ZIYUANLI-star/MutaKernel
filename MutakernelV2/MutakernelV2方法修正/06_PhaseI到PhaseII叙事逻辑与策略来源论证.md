## 1. 总纲：三段式叙事的"仪器校准"因果链

### 1.1 一句话骨架

> 变异探针是**已知故障的标定仪器**：我们先用它测量现有验证器放过了什么
> （Phase I，基线审计），再甄别"放过的"里哪些其实无信号（等价甄别），
> 最后检验"由确认盲区导出的定向压力规则"能否系统性关闭盲区并迁移到
> 自然缺陷（Phase II，CSE 反例搜索 + 外部语料）。

三段各自回答一个不可跳过的问题，且每段的**输出恰好是下一段的动机**：

| 段 | 回答的问题 | 输出 | 为什么下一段必须存在 |
|----|-----------|------|---------------------|
| Phase I 基线审计 | 基线验证器放过了什么？ | 1,646 探针中基线击杀 50.6%，527 个幸存者【中间数据】 | 幸存者混杂"真等价"（探针无信号）与"真盲区"（基线漏杀），不拆开则盲区规模不可解释 |
| 等价甄别 | 幸存者里哪些是真盲区？ | 不对称口径下的三分解：机器证明等价 / 见证非等价 / INCONCLUSIVE（Table 10） | 见证非等价的幸存者 = 实锤漏杀；"是什么输入逮到它们的"就是压力规则的经验来源 |
| Phase II CSE | 定向压力规则是否有效、有来源、可迁移？ | FaultToStressMap + 闭合率曲线（§5.6）+ 外部语料增益（E3） | —（叙事闭合：规则回到自然缺陷上兑现效用） |

### 1.2 因果链上不许断的三个环

1. **仪器合法性环**：探针是"已知注入故障"的程序，注入的故障类与位点
   由构造可知（方法V2_03 §3.2 的 probe schema）【已有数据·E1 探针
   manifest，1,646 = A757+B702+C178+D9，与 V1 逐 ID 吻合】。仪器读数
   （杀/存活）的可信性由 E0 配对翻转实验背书（修正基座 vs legacy，
   62 可配对中 2 翻转，3.2% [0.9, 11.0]）【已有数据·E0】。
2. **混杂消解环**：Phase I 的 527 幸存者是一个混杂总体。若直接把 527
   报为"盲区"，审稿人一句"里面有多少是等价变异体？"即可击穿——
   这正是引出等价甄别的**行文动机**：没有这一步，Table 10 是糊涂账。
3. **来源可追溯环**（本文档核心，§5）：Phase II 的 21 个压力策略必须
   同时给出先验来源（故障机理与文献）、经验验证（见证数据的对角结构）
   与防循环证明（交叉拟合 + 外部语料），三层缺一即被判"规则是拍脑袋
   凑出来的"或"规则是为杀自己的变异体定制的"。

### 1.3 论文行文顺序建议

- Section 3（方法）按"引擎与口径"组织：执行基座与严格 Oracle →
  探针生成与分类学 → 等价证据分级 → CSE 与 FaultToStressMap；
- Section 4/5（研究与实验）按本因果链组织：RQ4 先讲 Phase I + 等价

  规则带到自然语料（Table 6a/6b/7）；
- "策略来源三层论证"（本文 §5）建议正文压缩为一节 + 一张表

### 1.4 段间过渡句（可直接改写入论文）

三段式叙事最容易断裂的是段间衔接。以下过渡句固化衔接逻辑，
论文写作时按语境改写：

- **Phase I → 等价甄别**：*"527 个幸存探针并不能直接读作 527 个
  验证器盲区：一个幸存者既可能揭示基线的采样缺口，也可能只是
  一次语义上无效的变异。在拆开这一混杂之前，任何盲区规模的声明
  都是不可解释的。"*（承认混杂 → 引出甄别）
- **等价甄别 → Phase II**：*"73 个带见证的漏杀不只是计数——每个
  见证都记录了'哪种输入、哪个执行维度'第一次把该故障与原始行为
  区分开。这些 killing case 是定向压力规则的经验来源：规则不是
  被设计出来再找证据，而是从盲区的成因中被归纳出来、再受先验
  机理与折外验证的双重约束。"*（见证 → 规则来源）
- **Phase II 受控 → 自然语料**：*"到此为止，全部证据仍建立在
  我们自己注入的故障上。定向规则的效用主张因此只建立在两条
  独立证据线上：对未参与建图任务的探针的折外闭合率，以及在
  缺陷完全独立于本研究的四个公开语料上、同预算相对朴素增强的
  确认缺陷召回增益。"*（防循环 → 效用兑现）

## 2. Phase I：基线审计与"混杂的幸存者"

### 2.1 口径

- 对象：90 个基线接受的 KernelBench L1/L2 内核 × 16 算子一阶变异、
  每 (kernel, operator) 降采样 ≤3，共 1,646 探针【已有数据·E1 manifest】；
- 协议：B1 基线协议（5 组固定 shape 随机输入 + allclose）在**修正
  基座**上重放；对照门控——逐内核未变异原始对照双臂通过才进入分母
  （E0 教训固化）【已有数据·E0/E1 设计】；
- 结果（中间口径）：基线击杀 50.6%，527 个幸存者【中间数据】。

### 2.2 行文要点：幸存者不可直接解释

幸存者 = "基线测不出它与原始内核的差别"，其成因二分：

1. **真等价**：变异在语义上无效果（冗余 cast、被算法吸收的扰动），
   仪器本身无信号——不是盲区；
2. **真盲区**：变异确实改变行为，但基线的采样点未激活/未观察到
   （RIPR 链条上的某环失败，方法V2_07 §3.4）。

论文必须在此处**明说**：这两类在 Phase I 的观测下不可区分，因此
527 这个数字本身没有解释力；把它拆开是下一节的任务。这一"承认
不可解释"的写法既是诚实性，也是叙事引擎——审稿人被带着问出
"那怎么拆？"，正文顺势进入等价甄别。

## 3. 等价甄别：不对称口径

### 3.1 两个方向的证据标准刻意不对称

| 方向 | 判定标准 | 措辞纪律 |
|------|---------|---------|
| **非等价** | 一次**健全见证**即成立：严格 Oracle（结构/dtype/NaN 位置感知）下，original 通过 + mutant 违反参考语义的三路判定（A 通过 / B 失败，01 文档 §1），见证可复放 | "witnessed non-equivalent"，永久成立 |
| **等价** | **永不正面宣称**。只报三层：(a) 机器证明子集（源码恒等/版本化静态规则，目前 9/1,646 全部为 `dead_host_constant` v1.0【已有数据·E1】）；(b) "未被区分"（LIKELY_EQUIVALENT，在被测域内未被反证）；(c) 人工盲审等价率（带 κ 与 CI）【待跑·盲审】 | 禁用 confirmed_equivalent；统一 "unfalsified under the tested domain"（01 文档 §3） |

不对称的认识论根据：非等价是存在命题（一个反例即证明），等价是
全称命题（测试永远无法证明）。这一句建议原文写进论文，它是整个
甄别口径的一行式辩护。

### 3.2 分级证据协议（E1 equiv phase 已实现）

每个幸存探针执行：**20 个随机轮 + 位点匹配的定向压力轮**（按探针
故障类查策略元数据选取 6 个定向策略 × 2 重复）【已有数据·E1 实现，
`run_e1_probe_study.py`】。判级规则：

- 任一有效轮见证发散 → WITNESSED_NON_EQUIVALENT（终态）；
- 全部计划轮通过 → LIKELY_EQUIVALENT；
- **部分证据**（墙钟预算耗尽但已完成轮次无发散）：随机轮 ≥20 全过
  且定向压力轮 ≥8 过 → 仍判 LIKELY_EQUIVALENT，但 evidence 字段
  显式记录 `budget_exhausted` 与逐轮计数，供下游证据分层；
- 否则 INCONCLUSIVE（按超时/资源/基础设施细分类，**一律不计入
  杀伤也不计入等价证据**，保留在分母中可见）。

门槛（20/8）与轮预算在观测前写死于代码常量并进 run manifest
【已有数据·E1 manifest 含 `partial_evidence_thresholds`】。

### 3.3 与 Table 10 的对接

甄别完成后，527 幸存者三分解落入 Table 10 的三列：
Machine-proven eq. / Witnessed non-eq., survived / INCONCLUSIVE。
截至 517/527 的中间数据：**73 个实锤漏杀**（witnessed non-equivalent
且基线存活）【中间数据】。这 73 个是全文的关键资产：每一个都携带
"哪个策略/维度的哪一轮逮到它"的 killing case 元数据——策略来源
论证的经验层（§5.2）直接建立在这上面。

## 4. Phase II：CSE 全策略反例搜索的定位

### 4.1 目标不对称

CSE（反例搜索引擎，05 文档）在审计模式下的目标是**尽力证伪等价
假设，而非确认等价**。它对每个幸存探针以全策略矩阵搜索反例：

- 找到 specification violation → 盲区确认 +（若 EMD 先验为
  LIKELY_EQUIVALENT）平反为 false equivalent，q_post = 0；
- 仅 bitwise 发散 → 只推翻严格实现等价，单列不计缺陷（01 文档）；
- 未找到 → 等价等级不升级，只积累"未被区分"的轮次证据。

每轮结果进入 EMD 证据链第一层（证据向量），聚合后支撑第二层
有序等级（02 文档 §1.5 三层输出）。**任何硬结论只建立在可复放
反例上，不依赖等价置信度数值**——这条纪律是等价甄别与 Phase II
共享的地基，行文中应显式重申一次。

### 4.2 与验证模式的关系（一台引擎两种调用）

审计模式的反例同时产出 FaultToStressMap 的证据条目
（closure_rate、sole_detector、escape_mechanism，方法V2_07 §3.5）；
验证模式（Mode B）在线只消费冻结后的 map + 静态位点指纹，不执行
任何变异体。两模式间唯一的桥是 map——这正是"测试规则来源"在
系统架构上的物化：**规则 = map 条目，条目 = 带反例 ID 的受控证据**。

## 5. 策略来源三层论证（本文档核心）

论证结构：**先验层**回答"规则为什么先验上该有效"（机理 + 文献），
**经验层**回答"规则实际有效吗"（见证数据 + 消融），**防循环层**
回答"这套论证是否自我循环"（两道防火墙）。三层对应审稿人的三连问，
行文按此顺序推进。

### 5.1 先验层：21 策略 ↔ 故障类 ↔ 触发机理 ↔ 文献

先验锚点是 16 算子四族分类学（A 算术 / B 并行 / C 数值 / D LLM

知识。每个策略的 `target_fault_classes` 元数据随代码发布、观测前
冻结（方法V2_02 §4.2）【已有数据·代码 + freeze 纪律】。

### 5.3 防循环层：两道防火墙

审稿人的元攻击："你们用自己注入的故障验证自己设计的规则，再用
这些规则宣称验证器更强——整条链在自产自销。"两道防火墙分别斩断
"针对性 = 作弊"与"效用自证"两个环：

**防火墙一：审计模式中的针对性是仪器用途，不是作弊。**
探针本来就是已知故障的标定仪器（§1.2 环 1）；用定向策略去杀已知
故障类的探针，等同于用标准样品校准检测仪——校准阶段的"针对性"
恰是方法论要求，而非泄漏。作弊指控只在"用校准数据宣称对未知对象
的效用"时才成立，那由防火墙二处理。行文上这段要放在 map 构建
之前说清，否则审稿人带着怀疑读完整个 RQ4。

**防火墙二：map 的效用从不在探针上自证。** 两条独立证据线：

1. **§5.6 任务簇交叉拟合**【待跑】：90 个源任务分 k 折；每折的
   map 只用其余任务的探针构建，评估只在留出折的探针上进行（同任务
   探针不跨折）。构建折与评估折任务不相交 → "map 对没参与建它的
   任务的探针仍有预测力"才计入闭合率主张；非交叉拟合曲线只作
   上界进附录。
2. **E3 外部语料迁移**【待跑】：C2–C5 四个自然语料（CUDA-L1 /
   AI-CUDA-Engineer / TritonBench-G / KernelBench-samples）的缺陷
   **不是我们注入的**，其生成系统、语言、缺陷分布均独立于探针
   语料；map 在任何 C2–C5 subject 执行前内容寻址冻结【已有数据·
   freeze 纪律，蓝图 §5.1.1】。效用主张的最终形态是：**同预算下
   M-dir 对预算匹配基线 B3（IID-32）的确认缺陷召回增益**
   （Table 7），而非任何探针上的数字。

一句可直接入论文的总括：*先验层给出规则的领域学来源，经验层在
受控故障上验证规则，防循环层保证验证与主张使用不相交的证据——
测试规则在进入任何效用声明之前，已经历"机理可解释 → 受控可复现
→ 折外可预测 → 语料外可迁移"四级审查。*
