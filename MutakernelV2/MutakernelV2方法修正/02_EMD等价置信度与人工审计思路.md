## 1. EMD 的角色重定位

V1 的问题：EMD 的二值标签（equivalent / non-equivalent）被当作接近 ground truth
使用，而它本质是启发式 triage。V2 的定位：

> **EMD 是一个"被评估的分诊方法"，不是 ground truth。**
> 它输出压力测试前的等价置信度 q_pre；独立人工审计提供校准标签；
> 完整压力测试提供反例挑战，更新为 q_post。

### 1.0 第二次重定位：EMD 是"探针价值过滤器"（2026-07-21 补充）

在"原始候选内核是最终待验证对象、变异体只是故障探针"的 V2 框架下
（见 00 文档 §2.1），EMD 的职责进一步收缩：

> **EMD 的作用是剔除没有测试价值的等价探针，避免系统根据一个实际上不改变
> 行为的变异体生成无意义的定向测试。它是测试生成引擎里的软优先器，
> 不给任何变异体做最终等价认证。**

这带来一个化解"EMD 复杂、主观、不确定"焦虑的关键结构性变化——
**论文硬结论的严格性负担从 EMD 转移到机器可查验的反例上**：

- 每个 genuine validator gap 由一个可复放的具体反例证明
  （original 通过 + mutant 违反参考语义的三路判定），完全不依赖 EMD 的判断；
- EMD 判错的代价被限定为预算层面：等价探针误判为非等价 → 浪费若干测试轮次；
  非等价误判为等价 → 损失一个探针的指导（同故障类的其他探针可补偿）；
- 从未被杀死又无机器证明的残余变异体，诚实标注 **unresolved / INCONCLUSIVE**
  留在分母中，不再强求 EMD 给出"确定、准确"的定性。

推论：V2 的正确路线不是"把 EMD 做准"，而是"把证据结构改到不依赖 EMD 的准确性"。
人工审计（下文）的首要对象因此也从"验证 EMD 标签"转为
"独立确认反例与缺陷"，EMD 校准降为第二优先级（服务 RQ3 的方法学分析）。

### 1.1 q_pre 的证据向量

来自四层：源码归一化（Layer 0）、静态规则命中（Layer 1）、轻量动态探测的轮数与
结果（Layer 2，改名 lightweight behavioral probing，明确它只是低成本第一轮挑战）、
LLM verdict + confidence（Layer 3，只作特征，不作最终 oracle）。

### 1.2 标签体系（采纳 FSE 计划）

- `EQUIVALENT_MACHINE_PROVEN`：仅限机器可检查证明（源码恒等/静态规则）；
- `LIKELY_EQUIVALENT`：人工/LLM 判断支持等价但无证明；
- `NON_EQUIVALENT`：存在已复现的反例；
- `INCONCLUSIVE`。

`provably equivalent` 一词保留给第一类；历史"349 provably equivalent"必须按此
重新表述（多数应降为 LIKELY_EQUIVALENT）。

### 1.3 q_post 更新规则

- 找到 specification violation（见 01 文档）→ q_post = 0，计为 false equivalent；
- 仅 exact divergence → 严格实现等价置信度归零，契约等价置信度保留；
- 全部有效轮通过 → 经验性提升，但表述永远是"在被测域内未被反证"。

### 1.4 删除伪概率公式

历史 Tier 3 的 `1 - 1/(N+1)` 下界不成立（轮次非独立同分布、策略是定向构造的）。
替代：

- 若审计标签量充足 → 用标签校准（logistic/isotonic），**必须留 holdout**：
  校准标签与评估 MutaKernel 的标签不得同源复用（否则三处共用一套标签形成循环）；
- 标签不足 → 诚实输出 ordinal（low/medium/high），报告与审计标签的秩相关。

### 1.5 "置信度"的最终形态：三层输出结构（2026-07-21 定稿）

对 GPT"EMD 输出改为等价置信度"建议的裁定：**采纳"从二值到不确定性表达"，
不采纳"直接输出概率数值"**。理由：(a) 启发式分数改名叫置信度不构成概率，
审稿人有权索要 calibration error；(b) 校准负样本稀缺（历史平反样本仅 21 个）
且有标签循环风险；(c) 数值置信度必然伴随阈值（V1 的 0.98 白名单已被诟病），
每个阈值都是攻击点。落地为三层：

| 层 | 内容 | 用途 |
|----|------|------|
| 第一层：证据向量（内部，永远保留） | Layer 0 恒等与否、Layer 1 规则命中、Layer 2 轮数/策略/结果、Layer 3 verdict 与理由 | 原始数据，一切口径由此派生、可复算 |
| 第二层：有序等级（论文主口径） | EQUIVALENT_MACHINE_PROVEN / LIKELY_EQUIVALENT / INCONCLUSIVE / NON_EQUIVALENT_WITNESSED，每级带机器可查验的准入条件 | 论文表述与统计分层；无阈值敏感性 |
| 第三层：校准研究（有 holdout 标签才做） | 用证据向量训练校准器，报告 AUC / Brier / 可靠性图 | RQ3 的分析贡献：评估 EMD 预测效度——置信度是**被研究的对象**，不是被依赖的组件；负结果可发表 |

贯穿纪律：任何硬结论（gap 数、false acceptance 下界、mutation score 分母）
不得依赖置信度数值；数值分数只做三个软用途——审计模式预算分配
（Tier 的连续化）、探针优先级排序、RQ3 分析。硬结论一律靠可复放反例。

## 2. 循环论证的根除（V1 最大的方法学软肋）

V1 的问题链：534 个存活变异体 → MutaKernel 先杀 166 → 剩 368 进 Opus 审计 →
用审计结果算出 99.82%。**166 个检出阳性在审计前就被移出了审计池**，等于用检测器
自己筛过的样本评估检测器（resubstitution）。V2 的修正（已写入协议）：

1. 审计队列在检测器结果**封存后**、按冻结规则机械生成，包含全部告警 + 全部未决
   subject + 从"全通过"层中预注册分层抽样的阴性样本；
2. 审计者双盲：看不到哪个策略报警、EMD tier、LLM 答案、历史论文标签；
3. 两名独立主标注 + 第三方仲裁，先算 pre-adjudication agreement/kappa/混淆矩阵
   再仲裁；
4. `NO_DEFECT_FOUND` 不是真阴性；prevalence 只能带抽样权重和置信区间报告。

## 3. 四个审计人群不得互相借标签

| 人群 | 对象 | 回答 |
|------|------|------|
| A | 真实生成 kernel（597 帧重跑后） | 自然误接受下界（RQ1）+ 各验证器告警精度 |
| B | 重跑 1,646 后机械导出的新变异体队列 | EMD 校准 + 变异分数的分母清洗（RQ3） |
| C | 1,020 条历史失败样本 + 已确认自然缺陷的开放编码 | 分类学代表性（RQ3 的另一半） |
| D | TaskD 104/101 队列对齐 + 修复重分类 | 次级案例 |

**注意历史 534 不能自动定义人群 B 的新帧**——修正后的 Phase I 可能产生不同的
存活队列（状态污染修复后，L2 的假 kill 会回流为 survivor）。

## 4. EMD 敏感性分析（回应 Reviewer B Q2）

冻结若干变体后各跑一遍，报告标签翻转率：静态规则开/关、动态轮数（28/56/112）、
LLM 模型（DeepSeek-R1 vs 另一家族）、prompt 版本、轮数上限、置信阈值
（0.7/0.9/0.98）。每层与独立标签对比，绝不用某层自己的决定当自己的真值。

## 5. 工作量现实评估

人群 A（告警并集 + 阴性抽样，双标注）与人群 B（新队列或分层金集，双标注）合计
预计数百条人工判断，且需要 GPU 能力的标注者。这是 V2 时间线上的最大人力瓶颈，
建议尽早确定标注者人选并先跑 20–30 条 pilot 校准码本（协议已规定流程）。
若人力不足，最低可辩护设计是：人群 A 全告警 + 每层 N 条阴性、人群 B 预注册
分层金集，其余以 INCONCLUSIVE 显式保留在分母中。
